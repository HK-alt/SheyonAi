# Sheyon Ai

Sheyon Ai is an Expo (React Native) app — an AI assistant with chat, research, and curriculum features.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

3. Copy environment variables

   ```bash
   cp .env.example .env
   ```

   Fill in Supabase and other keys as described in [docs/INTEGRATION_GUIDE.md](docs/INTEGRATION_GUIDE.md).

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start Expo dev server |
| `npm run android` | Run on Android |
| `npm run ios` | Run on iOS |
| `npm run web` | Run in browser |
| `npm run lint` | Run ESLint |
